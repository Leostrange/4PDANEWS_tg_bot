# 🤖 Telegram-бот «НовостИИ»

Бот анализирует посты из Telegram и создаёт структурированные сводки с помощью любого AI-провайдера.

## Быстрый старт

### 1. Получи токен бота
1. Открой Telegram, найди [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Задай имя и username
4. Скопируй токен

### 2. Настрой конфигурацию

```bash
# Установи зависимости
pip install -r requirements.txt

# Скопируй пример конфига
cp .env.example .env

# Отредактируй .env — заполни BOT_TOKEN, API_KEY, API_BASE_URL, MODEL
nano .env
```

### 3. Запусти

```bash
python bot.py
```

### 4. Пользуйся

1. Найди своего бота в Telegram
2. Нажми `/new`
3. Пересылай посты из сохранённой папки
4. Нажми `/gen` — получи BBCode сводку для 4PDA обычным текстом

## Настройка AI-провайдера

Бот работает с любым API, совместимым с OpenAI `/v1/chat/completions`:

| Провайдер | `API_BASE_URL` | `MODEL` |
|-----------|---------------|---------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` |
| OpenRouter | `https://openrouter.ai/api/v1` | `anthropic/claude-sonnet-4` |
| Together | `https://api.together.xyz/v1` | `meta-llama/Meta-Llama-3.1-70B-Instruct-Turbo` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |
| LM Studio | `http://localhost:1234/v1` | *(модель из настроек)* |
| Ollama | `http://localhost:11434/v1` | `llama3.1` |

## Кастомный промпт

Файл `system_prompt.md` содержит правила форматирования сводок.

**Как обновить:**
1. Отредактируй `system_prompt.md`
2. Перезапусти бота

Промпт загружается при старте. Для обновления без перезапуска — добавь команду `/reload` (пока не реализована).

## FAQ

**Q: Как добавить нового провайдера?**
A: Просто поменяй `API_BASE_URL` и `MODEL` в `.env`. Любой API с совместимым форматом `/v1/chat/completions` подойдёт.

**Q: Можно ли запускать на сервере?**
A: Да. Используй systemd, screen или docker. Бот работает асинхронно и потребляет мало ресурсов.

**Q: Как изменить правила форматирования сводок?**
A: Отредактируй `system_prompt.md`. Там описаны все правила: категории, цвета, спойлеры, структура.

**Q: Бот не отправляет сводку — что делать?**
A: Проверь логи в консоли. Убедись, что API работает (`/test`) и модель поддерживает нужное количество токенов.

## Развёртывание на Railway

1. Подключи этот репозиторий через **New Project → Deploy from GitHub repo**. В репозитории есть `railway.toml` с командой `python bot.py`.
2. В **Variables** сервиса задай `BOT_TOKEN`, `API_KEY`, `API_BASE_URL` и `MODEL` из своего `.env`. Добавь `ALLOWED_USER_IDS` со своим числовым Telegram user ID (несколько ID через запятую). Пустой список разрешает всем обращаться к платному AI API. Секреты не добавляй в Git. Параметры `MAX_TOKENS`, `TEMPERATURE`, `MAX_POSTS`, `MAX_CHARS` необязательны.
3. Для сохранения постов, готовых сводок и счётчиков после обновлений добавь к сервису **Volume** с mount path `/data` и установи `DATA_FILE=/data/sessions.json`. Без тома данные могут исчезнуть при новом развёртывании.
4. Примени изменения и смотри **Deploy Logs**: должно появиться «Бот запущен! Ожидаю сообщения...». Проверь `/start`, затем `/test` и генерацию из пересланного текстового поста.

Это фоновый процесс с long polling: публичный домен и `PORT` не нужны. Держи одну реплику сервиса и останови другие запущенные копии с тем же токеном Telegram. Railway оплачивается по действующим условиям аккаунта; перед запуском проверь лимиты и бюджет проекта.

`/test` проверяет endpoint `/models`; некоторые совместимые провайдеры его не предоставляют. В таком случае проверь работу реальным `/gen`.
