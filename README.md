# 🤖 Telegram-бот «НовостИИ»

Бот анализирует посты из Telegram и создаёт структурированные сводки с помощью любого AI-провайдера.

## Быстрый старт

### 1. Получи токен бота
1. Открой Telegram, найди [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Задай имя и username
4. Скопируй токен

### 2. Настрой конфигурацию

```bash
# Установи зависимости
pip install -r requirements.txt

# Скопируй пример конфига
cp .env.example .env

# Отредактируй .env — заполни BOT_TOKEN и ALLOWED_USER_IDS
nano .env
```

### 3. Запусти

```bash
python bot.py
```

### 4. Пользуйся

1. Найди своего бота в Telegram
2. Нажми `/provider` и укажи адрес API, ключ и модель в личном чате
3. Нажми `/new`, затем перешли нужные посты из своей папки Telegram
4. Нажми `/gen` — получи BBCode сводку для 4PDA обычным текстом

Папка Telegram остаётся у тебя. Bot API не даёт боту читать её содержимое: бот анализирует только сообщения, которые ты ему переслал или отправил.

## Настройка AI-провайдера

Бот работает с API, совместимыми с OpenAI `/chat/completions`. Вызови `/provider` в личном чате и отправь три отдельных сообщения: базовый HTTPS-адрес, API-ключ, ID модели. Бот пытается удалить сообщение с ключом после получения; проверь, что оно удалилось. Ключ сохраняется в файле сессий на хостинге и не показывается командой `/provider_status`. Команда `/clear` удаляет также ключ; `/new` сохраняет настройки AI.

| Провайдер | Базовый адрес API |
|-----------|-------------------|
| OpenAI | `https://api.openai.com/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |

ID модели должен соответствовать доступной тебе модели у выбранного провайдера. В этой версии настройка принимает HTTPS-адреса; `localhost` на сервере Northflank не указывает на твой компьютер.

## Кастомный промпт

Файл `system_prompt.md` содержит правила форматирования сводок.

**Как обновить:**
1. Отредактируй `system_prompt.md`
2. Перезапусти бота

Промпт читается заново при каждой генерации.

## FAQ

**Q: Как сменить провайдера?**
A: Ещё раз вызови `/provider` и отправь новые адрес API, ключ и модель. Старые настройки действуют до завершения мастера.

**Q: Можно ли запускать на сервере?**
A: Да. Используй systemd, screen или docker. Бот работает асинхронно и потребляет мало ресурсов.

**Q: Как изменить правила форматирования сводок?**
A: Отредактируй `system_prompt.md`. Там описаны все правила: категории, цвета, спойлеры, структура.

**Q: Бот не отправляет сводку — что делать?**
A: Проверь логи в консоли. Убедись, что API работает (`/test`) и модель поддерживает нужное количество токенов.

## Бесплатное развёртывание на Northflank

1. Создай аккаунт на [Northflank](https://northflank.com/) и выбери **Developer Sandbox**. Подключи GitHub и размести обновлённые файлы этого проекта в своём репозитории.
2. Создай проект и **Combined service** из репозитория `Leostrange/4PDANEWS_tg_bot`, ветка `main`. Для сборки выбери **Dockerfile** в корне. Оставь **1 instance**, без публичных портов: бот использует long polling.
3. В **Environment variables** сервиса задай `BOT_TOKEN` и `ALLOWED_USER_IDS` со своим числовым Telegram user ID (несколько ID через запятую). Пустой список разрешает любому человеку обращаться к боту. `API_KEY` на хостинге не нужен: укажи его внутри бота через `/provider`. Секреты не добавляй в Git. `MAX_TOKENS`, `TEMPERATURE`, `MAX_POSTS`, `MAX_CHARS` необязательны.
4. Для сохранения настроек AI, ключа, счётчика и текущей подборки постов после перезапуска нужен постоянный том: если тариф позволяет, подключи его к пути контейнера `/data` и установи `DATA_FILE=/data/sessions.json`. Без тома эти данные могут пропасть после нового развёртывания или перезапуска; исходные посты останутся в твоей папке Telegram.
5. Смотри логи сервиса: должно появиться «Бот запущен! Ожидаю сообщения...». Проверь `/start`, настрой `/provider`, затем `/test` и генерацию из пересланного текстового поста.

Останови другие запущенные копии с тем же токеном Telegram. Бесплатный хостинг не включает бесплатные запросы к выбранному AI-провайдеру — учитывай его отдельные лимиты и стоимость.

`/test` проверяет endpoint `/models`; некоторые совместимые провайдеры его не предоставляют. В таком случае проверь работу реальным `/gen`.
